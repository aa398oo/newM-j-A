# UX-22 动画系统：命令方块（Command Block Motion System）

> 定稿日期：2026-11-28。状态：**规格已定，实现待排期**（先落文档，后面按 §8 分批做）。
> 关联：UX-14（左侧 rail 骨架，已落地）、UX-20（动效令牌：120/180/260/340ms、`Motion.Ease = CubicBezier(0.2,0,0,1)`）。
> 本文替代 UX-20 里"通用过渡"的定位：UX-20 管页面级淡入淡出，UX-22 管**导航叙事**——所有主路径切换都由一个命令方块承载。

---

## 1. 设计理念

「平滑灵动（Smooth & Agile）」：不做生硬跳转，所有交互基于**物理隐喻**与**游戏化反馈**。

核心视觉锚点是一颗 **3D 等距命令方块**：它常驻在 rail 与内容区之间的视觉焦点上，导航不是"换页"，而是"方块被推下去 → 换成新内容"。

### 1.1 红线（不可违背）

| 红线 | 实现约束 |
|---|---|
| 只用 Compose 动画 API | `Animatable` / `Transition` / `spring` / `keyframes`；禁止 Lottie、禁止 WebView、禁止视频 |
| 禁止高清切图 | 全部 `Canvas` 几何绘制（等距方块 = 3 个多边形 + 高光；道具 = Path；粒子 = 三角形/五边形） |
| 禁止重度高斯模糊 | 景深只用 `graphicsLayer { alpha; scale; translation }`；必要的光晕用径向渐变 `Brush.radialGradient` 叠色，不用 `blur` |
| 单次互动 300–400ms | 每个场景总时长硬上限 400ms；超时即视为卡顿 bug |
| 可打断 | 任何时刻新输入必须能接管；不允许"等动画放完才响应" |
| 60/120fps | 动画只改 `graphicsLayer` 属性或 Canvas 绘制参数，不触发重组；禁止在每帧里 `mutableStateOf` 写值 |

### 1.2 已定视觉语言

- 方块：1.0 单位立方，等距投影（顶面菱形 + 左右侧面 + 1px 内描边），主色跟随 `Prefs.accent`。
- 道具进场方向：一律从**右侧内容区**撞向方块（用户视觉重心在右侧，反向会显得"后退"）。
- 撞击帧：方块 `scale 0.94` + 微位移 2dp + 4 帧内的 1.5dp 抖动（衰减正弦）。
- 弹开：`spring(dampingRatio = 0.32f, stiffness = 1100f)`，可过冲一次，不循环。

## 2. 状态机

### 2.1 三层结构

```
L1 导航层 RailState        用户手指在 rail 上的物理
L2 方块层 BlockState       方块自身的位移/旋转/缩放/材质
L3 事件层 PropState        道具（箭头/刷子/齿轮/丝带）的进场-撞击-退场
L4 碎裂层 ShatterState     子目录切换时方块碎裂 + 粒子
```

**关键决定：L1–L4 不是一个 `sealed class` 枚举状态机。** 原因是四层可以**并行**（用户在方块碎裂时仍能继续滑 rail），串行状态机会互相阻塞。做法是：

- **逻辑状态**用 `mutableStateOf(Stage)` 只表达"当前处于哪个阶段"（用于 a11y/测试/内容切换），**不驱动动画值**；
- **动画值**全部是 `Animatable<Float>`，由事件协程直接 `animateTo`；
- 一致性由一把 `MutatorMutex` 保证：新事件 `mutate {}` 会取消上一个事件的协程，`Animatable` 从**当前值**继续 → 天然可打断、可倒放。

### 2.2 状态转移

```
                 ┌──────────────────────────────┐
                 │            Idle              │◄──────────────┐
                 └──────┬───────────────┬───────┘               │
        drag start      │               │ tab click             │
                        ▼               ▼                       │
                 ┌────────────┐   ┌────────────┐                │
                 │  Dragging  │   │  Entering  │                │
                 └─────┬──────┘   └─────┬──────┘                │
        drag end       │                │ impact                │
                        ▼                ▼                       │
                 ┌────────────┐   ┌────────────┐                │
                 │  Settling  │   │  Impacted  │                │
                 └─────┬──────┘   └─────┬──────┘                │
        snap done      │                │ recoil+content swap   │
                        └───────────────►└───────────────────────┘

    子目录点击（独立轨道，可与上并行）：
    Idle ──loader hit──► Charging ──shatter──► Shattering ──settle──► Idle
```

### 2.3 优先级（谁取消谁）

| 高 → 低 | 事件 | 说明 |
|---|---|---|
| 1 | `Shatter` | 子目录进入，必须抢占 |
| 2 | `Impact(tab)` | rail 点击触发道具碰撞 |
| 3 | `Settle` | rail 拖拽结束的吸附 |
| 4 | `Drag` | 拖拽中，随时被上面三个顶掉 |

`Shatter` 抢 `Impact`：先 `blockScale.animateTo(1f)` 快速归位再碎，不从头播放。

### 2.4 唯一宿主

```kotlin
class MotionStage(private val scope: CoroutineScope, private val reduceMotion: Boolean) {
    private val mutex = MutatorMutex()

    // 方块
    val blockY = Animatable(0f)          // px
    val blockScale = Animatable(1f)
    val blockRotate = Animatable(0f)     // 度
    val blockMaterial = Animatable(0f)   // 0=命令方块原色 1=材质唤醒

    // 事件
    val propProgress = Animatable(0f)    // 0=未进场 1=撞到方块
    val propRecoil = Animatable(0f)      // 撞后弹开 0→1→0
    val shatter = Animatable(0f)         // 0=完整 1=完全碎裂
    val ribbonPhase = Animatable(0f)     // Fabric 丝带相位（0..360）

    var stage by mutableStateOf(Stage.Idle); private set

    fun play(intent: MotionIntent) = scope.launch {
        mutex.mutate { dispatch(intent) }   // 新事件自动取消旧事件
    }
}
```

`reduceMotion`（来自 `LocalAnimationsEnabled`）为 true 时：`animateTo` 全部换成 `snapTo`，`stage` 直接落终态——**同一个入口，不做第二套逻辑**。

## 3. 场景时序

时间轴单位 ms，总计即该场景的硬上限。

### 3.1 侧栏滑动（rail drag → 惯性 → 吸附）

| 轨道 | 0 | 100 | 200 | 340 |
|---|---|---|---|---|
| rail 位移 | 跟随手指 | 跟随 | 惯性衰减 | 吸附到位 |
| `blockY` | `drag * 0.32` | 同左 | 追到 `drag * 1.0`（滞后 60ms 用 `animateTo` + `spring`） | 回 0 |
| `blockRotate` | `drag * 0.06°` | — | 过冲 +2° | 回 0 |
| 方块落地 | — | — | `blockScale` 1→0.96→1（18ms 抖动） | — |

坠落是"带惯性"的：拖拽位移直接映射，松手后 `spring(initialVelocity = gestureVelocity * 0.35f)` 继续滑一小段再回弹。

### 3.2 下载（巨型箭头）

| 轨道 | 0 | 60 | 130 | 200 | 380 |
|---|---|---|---|---|---|
| 箭头 | 屏幕右侧外，`translationX = +120dp`，`alpha 0` | 冲入，`alpha 1`，`translationX 0` | 撞上方块顶面 | 被弹开 `translationX +34dp`，`alpha 0.9` | 淡出 |
| 方块 | — | `scale 1→0.94` | `scale 0.94`，`rotate -3°` | 过冲 `scale 1.03`，`rotate +1.5°` | 1.0 / 0° |
| 震动 | — | — | 4 帧正弦 1.5dp | 衰减 | — |
| 背景 | — | — | 撞击瞬间全屏 `#1E5EFF` 8% 闪 2 帧 | — | — |

### 3.3 个性化（刷子粉刷）

| 轨道 | 0 | 80 | 260 | 400 |
|---|---|---|---|---|
| 刷子 | 方块左侧外，`alpha 0` | 入画，`translationX 0` | 从左到右扫过（`progress 0→1`） | 右出画 |
| 材质 | 0 | 0 | 沿刷子轨迹**逐像素**显现（`clipRect` 从左到右 + 噪点纹理） | `blockMaterial = 1` |
| 方块 | — | `scale 1.0` | 轻微上下浮 1.5dp（解压感） | 保持彩色 |

材质显现用 `clipRect(right = width * progress)` 裁切一层"彩色方块"叠在"命令方块"上——两层面片，零额外开销。

### 3.4 设置（齿轮嵌入）

| 轨道 | 0 | 60 | 150 | 220 | 360 |
|---|---|---|---|---|---|
| 齿轮 | 右上外，`rotate -45°` | 飞向左上角，`rotate 0` | 扣合（`scale 1.06` 微弹） | 回 `1.0` | 留在方块上，淡出到 0.9 |
| 方块 | — | — | `rotate +2°`（被扣合的力） | 回 0 | — |
| 金属反光 | — | — | 齿轮边缘 `Brush.sweepGradient` 转 30° | — | — |

### 3.5 子目录点击（加载器撞击 + 碎裂）

| 轨道 | 0 | 50 | 120 | 260 | 400 |
|---|---|---|---|---|---|
| 加载器图标 | 从点击点飞向方块，`scale 0.6→1` | 撞上 | — | — | — |
| 方块 | — | `scale 0.92`，白闪 1 帧 | 碎裂开始 | — | 完全消失 |
| 碎片 | — | — | 8–14 片三角形/五边形向四周迸射 | 重力下坠 + 旋转 | 淡出 |
| 列表 | — | — | 列表从 `alpha 0, translationY 12dp` | 淡入 | 完全可交互 |

碎片参数**预计算**：一片 = `(angle, speed, size, spin, hue)`，全部在 `remember { List(n) { ... } }` 里生成，动画只用 `t` 计算位置 `p = p0 + v*t + 0.5*g*t²`，避免每帧随机。

### 3.6 Fabric 专属（丝带缠绕 → 材质唤醒 → 撞击）

| 轨道 | 0 | 120 | 300 | 380 | 450 |
|---|---|---|---|---|---|
| 丝带 | `phase 0`，`alpha 0` | 入场，`alpha 1` | 绕方块 1.5 圈（`phase 0→540°`） | 收束，`alpha→0` | — |
| 材质 | 0 | 0.1 | 0.5（随相位渐亮） | 1.0（流光渐变） | 撞击碎裂 |
| 方块 | — | — | 轻微呼吸 `scale 1±0.01` | 撞击 | — |

总时长 450ms **超出 400 红线**，处理：丝带与`撞击`重叠（第 380ms 开始撞），用户可感知的总等待仍是 400ms 内——红线约束的是"输入到界面可响应"，不是"所有视觉元素结束"。

## 4. API 组合

### 4.1 惯性滑动（核心：把指针速度交给 spring）

```kotlin
val railOffset = remember { Animatable(0f) }
val tracker = remember { VelocityTracker() }
var itemHeightPx by remember { mutableFloatStateOf(0f) }

Modifier.pointerInput(Unit) {
    detectVerticalDragGestures(
        onDragStart = { tracker.resetTracking() },
        onDragEnd = {
            val v = tracker.calculateVelocity().y
            scope.launch {
                val target = (railOffset.value / itemHeightPx)
                    .roundToInt() * itemHeightPx
                railOffset.animateTo(
                    targetValue = target,
                    animationSpec = spring(
                        dampingRatio = 0.78f,
                        stiffness = Spring.StiffnessMediumLow,
                        visibilityThreshold = 0.5f
                    ),
                    initialVelocity = v          // ← 惯性来源
                )
            }
        },
        onDragCancel = { scope.launch { railOffset.animateTo(0f, spring()) } }
    ) { change, delta ->
        tracker.addPosition(change.uptimeMillis, change.position)
        scope.launch { railOffset.snapTo(railOffset.value + delta) }
        stage.play(MotionIntent.Drag)
    }
}
```

**为什么不用 `animateDecay` + `splineBasedDecay`**：吸附目标已知，`spring(initialVelocity)` 一步到位、天然可打断；`animateDecay` 后再 `animateTo` 会在两段之间出现速度不连续。只有"无目标自由滑动"（如横向画廊）才用 decay。

### 4.2 坠落跟随（不重组）

```kotlin
val blockY by remember {
    derivedStateOf { railOffset.value * 0.32f }
}
// 只读 state 的 Composable 用 graphicsLayer 消费，不进重组
Modifier.graphicsLayer {
    translationY = blockY
    rotationZ = blockY * 0.06f
    scaleX = blockScale.value; scaleY = blockScale.value
}
```

**关键**：`blockY` 用 `derivedStateOf` 包一层，`graphicsLayer {}` 里读取发生在**绘制阶段**，不触发组合；千万不能写成 `val y = railOffset.value * 0.32f` 后再传给 `Modifier.offset(y.dp)`（那会在组合阶段读 state → 每帧重组）。

### 4.3 撞击与弹开

```kotlin
// 冲入：快出慢入，力量感来自"前 60% 走完 90% 距离"
propProgress.animateTo(1f, tween(130, easing = CubicBezierEasing(0.1f, 0.9f, 0.2f, 1f)))

// 撞击：两段式过冲
coroutineScope {
    launch { blockScale.animateTo(0.94f, tween(70)) }
    launch { blockRotate.animateTo(-3f, tween(70)) }
}
// 弹开 + 方块回弹（并列，不互相 await）
coroutineScope {
    launch {
        propRecoil.animateTo(1f, tween(90))
        propRecoil.animateTo(0f, spring(0.45f, 700f))
    }
    launch {
        blockScale.animateTo(1f, spring(0.30f, 1100f))   // 过冲一次
        blockRotate.animateTo(0f, spring(0.45f, 900f))
    }
}
```

需要"精确时间点"的（如白闪 1 帧）用 `keyframes`：

```kotlin
val flash = Animatable(0f)
flash.animateTo(0f, keyframes {
    durationMillis = 400
    0f at 0
    1f at 118 using LinearEasing
    0f at 152 using LinearEasing
    0f at 400
})
```

### 4.4 刷子 / 齿轮（Path 进度）

刷子扫过的"材质显现"不做逐像素，用 `clipRect` 裁切，成本 O(1)：

```kotlin
Canvas(...) {
    drawCommandBlock(scale = blockScale.value, accent = accent)
    if (materialProgress > 0f) {
        clipRect(right = size.width * materialProgress) {
            drawAwakenedBlock(phase = blockMaterial.value, accent = accent)
        }
    }
}
```

齿轮嵌入的"精准扣合"用 `spring(0.9f, 600f)`，不给过冲；扣合瞬间叠一层 `Path` 描边高光。

### 4.5 碎裂粒子

```kotlin
data class Shard(val angle: Float, val speed: Float, val size: Float,
                 val spin: Float, val hue: Float, val delay: Int)

val shards = remember(seed) { List(12) { Shard(...) } }   // 预计算，不进组合
val t = shatter.value                                  // 0..1，唯一动画值

Canvas(...) {
    shards.forEach { s ->
        val local = ((t - s.delay / 400f) / (1f - s.delay / 400f)).coerceIn(0f, 1f)
        val p = p0 + dir * s.speed * local + Offset(0f, 0.5f * 900f * local * local)
        rotate(s.spin * local, p) { drawPolygon(...) }
    }
}
```

`t` 来自 `shatter.animateTo(1f, tween(400, easing = LinearEasing))`——线性时间，物理量在绘制里算，避免多条 Animatable 同时跑。

### 4.7 性能纪律

1. **只改 `graphicsLayer`**：位移/缩放/透明度/旋转全部走 `graphicsLayer {}`，不碰 layout。
2. **state 读取下沉**：动画值用 lambda 参数（`Modifier.drawBehind {}`、`Canvas` 内读取）或 `graphicsLayer {}`，避免组合期读 state。
3. **`drawWithCache`**：方块几何、齿轮 Path、丝带基准点只在 size/accent 变化时重建。
4. **单 Canvas**：方块 + 道具 + 碎片放在同一个 `Canvas` 里按 z 顺序 `drawPath`，减少 layer 数量。
5. **禁止逐帧 `remember`/`mutableStateOf`**：所有派生量用 `derivedStateOf`。
6. **验收**：`adb shell dumpsys gfxinfo <pkg> framestats` 在 rail 拖拽 + 撞击期间 P90 < 16.6ms；Layout Inspector 中重组次数不随帧数增长。

## 5. Fabric 丝带伪代码

```kotlin
/**
 * 三条丝带绕方块一圈：靠近观察者的半圈画在方块之后，远离的半圈画在方块之前，
 * 形成"缠绕"错觉。丝带用三次贝塞尔，控制点沿椭圆分布并做 sin 扰动。
 */
@Composable
fun FabricRibbonWrap(
    phase: Float,            // 0..540 度，Animatable 驱动
    material: Float,         // 0..1 材质唤醒
    accent: Color,
    modifier: Modifier = Modifier
) {
    val density = LocalDensity.current
    val strokePx = with(density) { 7.dp.toPx() }

    Canvas(modifier) {
        val center = Offset(size.width / 2f, size.height / 2f)
        val radius = size.minDimension * 0.46f
        val flatten = 0.36f                     // 俯视压扁
        val blockHalf = size.minDimension * 0.22f

        // 先画"背面的半圈"（被方块遮住，所以先画）
        drawRibbonHalves(phase, center, radius, flatten, back = true, strokePx, accent)

        // 方块本体：未唤醒 → 命令方块；唤醒 → 彩色流光
        drawBlock(
            awakened = material,
            accent = accent,
            phase = phase
        )

        // 再画"正面的半圈"（压在方块上），形成缠绕
        drawRibbonHalves(phase, center, radius, flatten, back = false, strokePx, accent)
    }
}

private fun DrawScope.drawRibbonHalves(
    phase: Float,
    c: Offset,
    r: Float,
    flatten: Float,
    back: Boolean,
    stroke: Float,
    accent: Color
) {
    repeat(3) { i ->
        val base = phase + i * 120f
        val path = Path()
        // 8 个采样点：角度 θ = base + k*45°
        val pts = List(8) { k ->
            val a = Math.toRadians((base + k * 45.0))
            Offset(
                c.x + r * cos(a).toFloat(),
                c.y + r * flatten * sin(a).toFloat() +
                    sin(a * 2.0).toFloat() * r * 0.04f          // 轻微波浪
            )
        }
        // 半圈 = 4 段 cubics；控制点取相邻点的 1/3 处并向外扩 8%
        fun seg(from: Int, to: Int) {
            val p0 = pts[from]; val p3 = pts[to]
            val dir = (p3 - p0)
            val normal = Offset(-dir.y, dir.x).normalized()
            val c1 = p0 + dir * 0.33f + normal * (r * 0.05f)
            val c2 = p0 + dir * 0.66f + normal * (r * 0.05f)
            if (from == 0) path.moveTo(p0.x, p0.y)
            path.cubicTo(c1.x, c1.y, c2.x, c2.y, p3.x, p3.y)
        }
        // 背面：k=4..7 的采样点在下半圈（sin<0），先画
        val range = if (back) 4..7 else 0..3
        for (k in range) seg(k, (k + 1) % 8)

        // 渐变笔刷：沿丝带方向，色相随相位旋转
        val brush = Brush.linearGradient(
            colors = listOf(
                hue(accent, base),
                hue(accent, base + 80f),
                hue(accent, base + 160f)
            ),
            start = pts[range.first],
            end = pts[range.last]
        )
        drawPath(path, brush = brush, style = Stroke(
            width = stroke, cap = StrokeCap.Round, join = StrokeJoin.Round
        ))
        // 高光：同路径再画一条 1.5dp 的白色 20% 细线，偏移 -1.5dp
        drawPath(path, color = Color.White.copy(alpha = 0.22f),
            style = Stroke(width = stroke * 0.28f, cap = StrokeCap.Round))
    }
}

/** 材质唤醒：命令方块底色 → 主色系流光。material 是 0..1 的 Animatable。 */
private fun DrawScope.drawBlock(awakened: Float, accent: Color, phase: Float) {
    val base = Color(0xFF2E8B57)                      // 命令方块绿
    val body = Color.lerp(base, accent, awakened)
    val top = Color.lerp(body, Color.White, 0.22f + 0.10f * awakened)
    val side = Color.lerp(body, Color.Black, 0.18f)
    // 等距三面
    drawPath(topFace(), top)
    drawPath(leftFace(), side)
    drawPath(rightFace(), Color.lerp(side, Color.Black, 0.12f))
    if (awakened > 0.01f) {
        // 流光：sweepGradient 随 phase 转
        drawRect(
            brush = Brush.sweepGradient(
                colors = listOf(accent.copy(alpha = 0f), accent.copy(alpha = 0.45f * awakened),
                                accent.copy(alpha = 0f)),
                center = center
            ),
            alpha = 0.9f
        )
    }
    // 1px 内描边
    drawPath(outlineFace(), Color.Black.copy(alpha = 0.35f), style = Stroke(1.dp.toPx()))
}
```

**实现要点**
- `phase` 由 `Animatable` 驱动，`animateTo(540f, tween(300, easing = LinearEasing))`；不要用 `rememberInfiniteTransition`（无法与撞击时序同步、也无法被 `MutatorMutex` 打断）。
- 三条丝带的 `base` 相差 120°，视觉上像三股，实际绘制成本 3×4 段贝塞尔 + 3 条描边 ≈ 24 条 path，中端机也远低于 1ms。
- `flatten` 让椭圆看起来像俯视圆柱，配合方块的三面投影才像"绕着物体"。

## 6. 文件与接口规划

| 文件（均在 `app/src/main/java/dev/mineport/launcher/ui/motion/`） | 职责 |
|---|---|
| `MotionStage.kt` | 状态机 + 全部 `Animatable` + `play(intent)`；`rememberMotionStage()` |
| `MotionIntent.kt` | `sealed interface MotionIntent { Drag, Settle, EnterTab(tab), Shatter(loader) }` |
| `CommandBlock.kt` | 等距方块与材质唤醒绘制；`CommandBlock(stage, accent, modifier)` |
| `PropActors.kt` | 箭头 / 刷子 / 齿轮三条 `Canvas` 绘制，参数只有 `progress`、`recoil` |
| `ShatterField.kt` | 碎片预计算表 + 绘制 |
| `FabricRibbon.kt` | §5 的丝带实现 |

外部接线：
- `RootScreen.kt`：rail 手势 → `stage.play(Drag/Settle)`；tab 点击 → `stage.play(EnterTab(tab))`；在 rail 与内容区之间放 `CommandBlock(stage)`（固定 96dp 视觉宽度，不占点击区域）。
- `InstancesScreen.kt`：子目录点击 → `stage.play(Shatter(loader))`，列表内容在 `shatter > 0.6` 时切换（`derivedStateOf` 读，不重组整个列表）。
- `Motion.kt`：只保留页面级过渡与 `LocalAnimationsEnabled`；UX-22 的新增令牌（`ImpactMs = 130`、`ShatterMs = 400`、`RibbonMs = 300`）放这里统一管理。

## 7. 验收标准

- [ ] rail 拖拽时方块跟随滞后 60ms 内，松手有惯性并吸附（60fps 下无跳帧）
- [ ] 四个 tab 各触发对应道具，撞击帧方块 `scale` 到 0.94 再回弹
- [ ] 动画中途滑另一个 tab：旧道具在 ≤80ms 内被新道具顶掉，无残留
- [ ] 子目录点击：碎片 12 片，400ms 后列表可交互
- [ ] Fabric 场景：丝带绕 1.5 圈，材质唤醒后撞击碎裂
- [ ] 关闭「动效」开关后所有场景 0ms 完成，不出现空白帧
- [ ] `dumpsys gfxinfo` 在撞击瞬间无 extra frame（>16.6ms）
- [ ] 全程无 `Bitmap`/`Image`/`blur`，APK 体积不因动画增加
