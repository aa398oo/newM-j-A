## 三、Forge 安装（今天写的，最需要真机）

- [ ] **首次启动的进度提示**（D131）：点「启动游戏」后应立刻看到深色底 + 「准备运行时…」的字。
  - 首次启动要解包 182MB 运行时，30–60 秒是正常的；这段时间有字在变，不是卡死。
  - JVM 就绪后 2.5 秒自动撤掉提示层，交给游戏画面。
  - 如果一直是黑屏、连字都没有 → `setContentView` 之前就崩了，抓 `adb logcat -d -s AndroidRuntime:E`。
- [ ] **缺库拦截**（D130）：Forge 启动前会核对 classpath，缺库时横幅显示「Forge 启动缺少 N 个库」，不是黑屏。

- [ ] **准备**：先确认原版 1.20.1 已装（下载页「版本」→ 1.20.1 → 只装本体）。
- [ ] **装 Forge**：版本 → 1.20.1 → 安装页 → Forge 行 → 开始安装。
  - 期望日志顺序：`准备运行时` → `下载 …`（installer 5.9MB）→ `processor 1/6 … 6/6` → 完成。
  - **耗时**：arm64 上 6 个 processor 未知，先记总时长（`adb logcat -d | Select-String "ForgeJvmRunner|processor"`）。
  - **内存**：安装期 JVM 与游戏同配置（`-Xmx` = 设备推荐值）。若 OOM，logcat 会有 `java.lang.OutOfMemoryError` 或进程被 LMK 杀掉。
- [ ] **失败时**：错误对话框里应带 `--- 输出尾部 ---` 和异常栈（`ForgeInstaller.runProcessors` 会拼进去）；同时 `files/logs/forge-processor-<n>.log` 有原文。
  - 抓：`& $adb shell run-as dev.mineport.launcher cat files/logs/forge-processor-3.log`。
- [ ] **装完直接启动**（D121 的核心）：点「启动游戏」。
  - 期望：**不需要重启应用**（实例目录/用户名/分辨率都是实例的，安装 JVM 被复用）。
  - 期望日志：`MineportJVM: 复用已存在的 JVM, java.version=…` → BootstrapLauncher 起来。
  - 失败时抓：`& $adb logcat -d | Select-String "MineportJVM|BootstrapLauncher|NoClassDefFound|Module"`。
- [ ] **已知限制**：先玩过一局再回来装 Forge → 会提示「请先划掉本应用」；这是 HotSpot 只能建一次 JVM 的硬限制，不是 bug。

## 五、UX-22 六动画逐项

| 触发 | 期望 | 失败时看 |
|---|---|---|
| 切任意 tab（T1） | 方块缩放 0.94 + 旋转 -3° + 白闪 220ms，`spring(0.30/1100)` 弹回 | 方块位置是否被 rail 的 `padding` 挤歪 |
| 拖 rail 松手（T2） | 惯性回落，方块略滞后 | 是否有 1 帧抖动（`railPull.snapTo` 在协程里） |
| 进下载页（T3） | 巨型箭头从右侧冲入，撞方块后回弹（`propRecoil`） | 箭头起点是否在屏幕外（`size.width + 90dp`） |
| 进设置页（T3） | 齿轮从右上飞来，旋转 -45°→0° 扣合 | 8 齿是否被裁 |
| 进版本管理（T5） | 方块碎裂 12 块抛物线炸开（`gravity=900`） | 粒子是否穿出屏幕 |
| 装 Fabric 选版本（T6） | 三条丝带绕方块转一圈，材质从绿变主色 | 背面半圈 alpha 0.38 是否够暗 |

> 六个动画都是 **300–400ms 上限**、可打断（`MutatorMutex`：连续点两个 tab，前一个立刻让位）。

- [ ] **启动失败的屏幕提示**：玩完一局退出，再点「启动游戏」。
  - 期望：屏幕中间出现黑底白字提示「本进程已经运行过一次游戏，JVM 不能复用…」+ 一句「把本应用从最近任务里划掉再重开」，可长按复制。
  - 失败时看：是否只有黑屏（说明 `showBanner` 没挂到 root 上）。
- 若某页白屏：大概率是 Compose 里读了未初始化的 state；抓 `AndroidRuntime:E` 的堆栈。
- 若进游戏黑屏但日志无异常：看 `render_bridge` 的 GL 初始化，之前 GL4ES 的 FBO 路径踩过（`-Dorg.lwjgl.opengl.libname=libng_gl4es.so`）。
