# 视觉风格规范（v1）

> 定位：**暗色科技感 + 一点像素魂**。不是白开水的 Material 3，也不是 Minecraft 拟物。
> 目标：3 米外能认出是我们的 UI；游戏内 HUD 不抢视野。

## 一、风格三原则

1. **暗底为主**：OLED 省电、玩家习惯、游戏内容不刺眼。
2. **单色强调**：全局只有一个强调色（信号青绿），危险/警告才用琥珀与红，避免彩虹色。
3. **形状克制**：圆角统一、边框极淡、不用重阴影。层次靠明度差，不靠投影。

## 二、色板

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 背景 base | #0E1116 | 页面底色，近黑带蓝 |
| 表面 surface | #161B22 | 卡片、列表项 |
| 表面 elevate | #1F2630 | 弹层、选中项 |
| 描边 | #FFFFFF 6% | 1px，分隔不用分割线用描边 |
| 主色 primary | #22D3A6 | 信号青绿，按钮/选中/进度 |
| 主色按下 | #17B98F | |
| 强调 accent | #FFB020 | 启动、重要提示、光影档位 |
| 危险 danger | #FF5C5C | 崩溃、删除 |
| 成功 success | #4ADE80 | 安装完成 |
| 文字 primary | #E6EDF3 | |
| 文字 secondary | #8B98A5 | 说明、副标题 |
| 文字 disabled | #4A5563 | |

> 不用 FCL 的草绿（#3C8527 系）作为主色，避免被认成同一个产品。

## 三、形状与间距

- 圆角：卡片 16px、按钮 10px、输入框 10px、徽标全圆
- 间距基数 4px：页面边距 20、卡片间距 12、卡片内边距 16
- 边框 1px、透明度 6%；**不使用投影**，弹层用 elevate 表面色 + 描边
- 触摸目标最小 48×48dp；游戏内按键最小 56dp

## 四、字体

- 正文：系统 Sans（HarmonyOS Sans / Roboto）
- **数字与参数用等宽**（帧率、内存、版本号、下载速度）——这是科技感的关键细节
- 层级：页面标题 32 / 区块标题 22 / 正文 17 / 说明 14 / 标签 12
- 标题字重 600，正文 400，数字 500

## 五、动效（只做三条）

1. 页面切换：淡入 + 轻微上移，220ms ease-out
2. 按钮：按下缩放 0.97 + 涟漪；安装完成时按钮变成功色并打勾
3. 加载：三个 6px 方块依次呼吸（像素暗示），不用转圈；进度用横向条 + 具体数字

> 实现位置：`ui/motion/Motion.kt`。时长/曲线只有这一处定义（`Motion.ScreenMs`、`Motion.Ease`），
> 页面用 `EnterFromBottom`、按钮用 `Modifier.pressScale(source)`、加载用 `PixelDotsLoading`。
> 列表用 `Modifier.animateItem()` 做增删位移，不要再各写一套 tween 数字。

## 六、游戏内 HUD

- 摇杆：半透明圆环 + 中心点，按下时环变亮
- 动作键：**描边圆（1.5px）+ 极淡填充**，按下填充加深，不挡视野
- 动作轮盘：环形排列，中心显示当前动作图标；打开时背景压暗 40%
- 顶部功能栏：小胶囊，默认 30% 透明，触摸时变为不透明
- 所有 HUD 可整体调透明度（设置里 60%–100%）

## 七、三档主题

| 主题 | 说明 |
| --- | --- |
| 暗色（默认） | 上述色板 |
| 亮色 | 背景 #F5F7FA，表面白，主色不变，文字反转 |
| 像素 | 高对比 + 2px 直角边框 + 等宽字体全量，给怀旧玩家 |

## 八、品牌

- 应用图标：方块化的字母/F 组合，青绿单色，不用渐变
- 启动动画：方块从中心堆叠成图标，1.2 秒
